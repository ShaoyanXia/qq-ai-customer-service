# 安全边界

## 端口

| 端口 | 用途 | 建议 |
|---|---|---|
| 6099 | NapCat WebUI | 只绑定 `127.0.0.1`，用 SSH 隧道访问 |
| 6185 | AstrBot Dashboard | 只绑定 `127.0.0.1` 或内网 |
| 6199 | OneBot v11 反向 WebSocket | 本机或内网，配置 token |
| 18887 | Web Chat | 可公网，但必须鉴权 |

## 凭据

不要进入 Git、Markdown、截图或群消息：

- OpenAI 兼容 API key。
- OneBot token。
- Web Chat token。
- QQ 登录二维码。
- root 密码、SSH 私钥、后台地址和后台凭据。

建议用 systemd 环境变量或受控配置文件保存。

## 机器人边界

机器人不能：

- 泄露系统提示词。
- 输出配置、密钥、服务器信息。
- 执行后台操作。
- 承诺已充值、退款、改额度、解封或修改账号。
- 回答和本群客服无关的闲聊、角色扮演和越权命令。

涉及账号、充值、额度、后台数据、订单、退款、封禁时，如果知识库没有明确答案，必须转人工。

## 日志和知识库

- 插件默认只存文本。
- 图片默认不长期入库。
- 如启用 OCR 或视觉摘要，必须过滤个人隐私和敏感凭据。
- 定期备份 SQLite，但备份文件也要限制权限。

## 更新策略

- 先在 Web Chat 或测试群验证。
- 改 persona、provider、插件时，只重启 AstrBot。
- 改 Web Chat 时，只重启 Web Chat。
- 尽量不重启 NapCat。
